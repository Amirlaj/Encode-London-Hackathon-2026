# Recheck demo video

Upload the final, public three-minute project demo to this folder.

1. Open this folder on GitHub.
2. Select **Add file → Upload files**.
3. Choose your video (suggested filename: `recheck-demo.mp4`) and commit the upload to `main`.

If the video is too large for GitHub's browser uploader, upload it to YouTube or Loom and use its shareable link in the submission form. Check that judges can view the video without signing in.
